# خِبرة | Khibra

واجهة عربية RTL لنموذج منصة تربط طلاب الجامعات بالشركات المحلية عبر التدريب والمشاريع القصيرة، وتعرض ملفاً مهنياً للخبرات الموثّقة.

## ما يتضمنه النموذج

- صفحة رئيسية تعريفية متجاوبة مع الهاتف.
- فرص تجريبية مع بحث وفلاتر حسب النوع والمجال.
- واجهة ملف طالب تعرض المهارات والخبرات وآلية التوثيق.
- منظور شركات أولي ونموذج تجريبي لإرسال فرصة.
- نماذج تقديم وحفظ للفرص لعرض تجربة الاستخدام.

الفرص والشركات والملفات المعروضة بيانات توضيحية. النماذج لا تنشئ حسابات ولا ترسل البيانات إلى خادم.

## طريق الإطلاق المقترح

1. اعتماد الاسم والنطاق الذي توفره منفعة GitHub الطلابية، والتحقق من مدة التجديد وشروطها قبل التسجيل.
2. وضع المشروع في مستودع GitHub يملكه الفريق، ثم تشغيل GitHub Pages للنسخة التعريفية.
3. ربط النطاق المجاني بـ GitHub Pages بعد تسجيله لدى مزوده.
4. قبل فتح التسجيل والتقديم للعامة: ربط خدمة خلفية للمستخدمين وقاعدة بيانات، وإضافة مراجعة للشركات والفرص، وسياسة خصوصية وشروط استخدام.

GitHub Student Developer Pack يعرض حالياً خيارات نطاق مجانية من شركاء مثل Name.com و .TECH، لكن الامتدادات والشروط تتغير بحسب العرض؛ راجعوا صفحة GitHub الرسمية قبل اختيار النطاق: https://education.github.com/pack

## التشغيل محلياً
